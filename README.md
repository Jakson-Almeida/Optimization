# Otimização

Repositório dos trabalhos da disciplina de Otimização. São **quatro trabalhos** no total, cada um avançando na classe de métodos (programação linear, programação não linear e assim por diante). A entrega de cada um inclui **resumo estendido** e **apresentação no formato de congresso**.

## Tema

Os **três primeiros trabalhos** tratam do mesmo problema, com o modelo sendo refinado a cada etapa:

> Operação ótima de uma microrrede com geração fotovoltaica, armazenamento em bateria e conexão com a rede principal.

A formulação inicial é de **programação linear inteira mista (MILP)** para o gerenciamento de energia (quando comprar/vender da rede, quando carregar/descarregar a bateria, como usar a geração FV). Os trabalhos seguintes evoluem esse modelo — por exemplo, para programação não linear, incertezas, degradação de bateria ou multiobjetivo.

O **quarto trabalho** aborda um problema pré-estabelecido pela disciplina, independente deste tema.

Referências de partida e de evolução estão em [`links_microrrede_otimizacao.txt`](links_microrrede_otimizacao.txt).
